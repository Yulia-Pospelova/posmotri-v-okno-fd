# Video Search Interface

Интерфейс поиска видео с динамической подгрузкой контента.

Проект выполнен в рамках учебной практики по вёрстке и работе с DOM/API.

## Описание

Страница включает:

- Видео-превью
- Форму поиска по городу и времени суток
- Кастомные чекбоксы
- Список карточек видео
- Кнопку загрузки дополнительных карточек
- Обработку состояний загрузки и ошибок

Видео и карточки подгружаются с внешнего API.

## Технологии

- HTML5
- CSS3
- JavaScript
- Flexbox
- Методология БЭМ
- Работа с DOM
- Fetch API
- Accessibility-паттерны
- Prettier

## Особенности

- Кастомные элементы формы
- Динамическое переключение видео
- Состояния hover / focus / active
- Прелоадер во время загрузки данных
- Обработка ошибок API
- Семантическая разметка
- Улучшенная доступность интерфейса
